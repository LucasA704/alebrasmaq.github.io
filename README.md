# Alebrasmaq - Site v3

Esta pasta contém:
- index.html atualizado
- 4 fotos reais de higienização de uma lavadora Electrolux

## Como publicar no GitHub
1. Faça backup do site atual.
2. Substitua o `index.html` atual por este `index.html`.
3. Envie também as quatro imagens para a mesma pasta do `index.html`.
4. Aguarde o GitHub Pages atualizar o site.

As imagens são usadas no HTML pelos nomes:
- higienizacao-electrolux-antes.jpg
- higienizacao-electrolux-tanque-limpo.jpg
- higienizacao-electrolux-cesto.jpg
- higienizacao-electrolux-peca.jpg
